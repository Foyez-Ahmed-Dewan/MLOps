# FastAPI Practice Repository

This repository contains my hands-on practice while learning **FastAPI backend development**.  
Each folder represents a specific concept implemented with working code.

---

## 📂 Project Structure

### 1️⃣ `1_funda`
**FastAPI Fundamentals**
- HTTP Methods: `GET`, `POST`, `PUT`, `DELETE`, `PATCH`
- Request & Response handling
- Pydantic `BaseModel`

---

### 2️⃣ `2_middleware`
**Middleware Implementation**
- Logging middleware
- Request timing middleware
- Rate limiting middleware

---

### 3️⃣ `3_dependency_injection`
**Dependency Injection**
- Single dependency
- Multiple dependencies
- Nested dependencies

---

### 4️⃣ `4_database_integration_mysql`
**Database Integration (MySQL + SQLAlchemy)**
- Engine configuration
- Session management
- Model creation
- CRUD operations

---

### 5️⃣ `5_database_migration`
**Database Migration with Alembic**
- Alembic initialization
- Autogenerated migrations
- Upgrade & downgrade
- Schema version control

---

### 6️⃣ `6_jwt`
**JWT Authentication**
- Password hashing (bcrypt)
- Token generation
- Token verification
- Protected routes
- OAuth2 password flow

---

## 🛠 Tech Stack
